# Lanternsea
A collectible card game on the Dark Sea: open packs of light-spirits, build your deck, and sail island by island to the Black Lighthouse.
Play: https://bordingcode.github.io/lanternsea/ — built by Spilsmedjen. See DESIGN.md.
(Formerly "Lygtebærer" — renamed to English in 0.2.0; old saves carry over.)
Tests: `node tests/test.js`
